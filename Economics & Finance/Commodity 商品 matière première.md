# Definition
**商品**（commodity，法 matière première / produit de base），在金融语境中通常指**大宗商品**：标准化、可互换（fungible）的基础原材料或初级产品。同一等级的商品无论由谁生产，市场上视为无差别，因此价格主要由全球供求决定，而非品牌。

注意区分：日常经济学中的"商品"（goods，法 marchandise / bien）泛指用于交换的劳动产品；本条目侧重作为[[Asset 资产 actif|资产类别]]的 commodity。

# Classification
- **能源**（energy）：原油（WTI、Brent）、天然气、煤炭。
- **金属**（metals）：
  - 贵金属（precious metals）：黄金、白银、铂、钯。
  - 工业金属 / 基本金属（base metals）：铜、铝、锌、镍。
- **农产品**（agricultural）：大豆、玉米、小麦、棉花、糖、咖啡。
- **畜产品**（livestock）：活牛、瘦肉猪。

也常分为 hard commodities（开采所得，如能源、金属）和 soft commodities（种植或养殖所得）。

# Market
- **现货市场**（spot market）：即时交割。
- **期货市场**：大部分交易通过标准化的[[Future 期货 contrat à terme normalisé|期货]]合约进行，主要交易所有 CME / NYMEX、ICE、伦敦金属交易所（LME）、上海期货交易所、大连商品交易所、郑州商品交易所。
- 投资者也可通过商品 ETF、商品指数（如 Bloomberg Commodity Index）间接投资。

# Characteristics
- 价格受天气、地缘政治、库存、汇率（多以美元计价）影响，波动性较高。
- 与[[Inflation 通货膨胀 inflation|通货膨胀]]常呈正相关，因此常被视为抗通胀资产（inflation hedge）。
- 本身不产生现金流（无股息、利息），收益来自价格变动和期货展期收益（roll yield）。
- 期货曲线形态：远期价格高于现货称 contango（期货升水），低于现货称 backwardation（期货贴水）。
