# Introduction

The imperfect (*l'imparfait*) is a simple past tense of the indicative. It presents a past situation **from the inside**, without its beginning or end: background, description, state, habit, or an action in progress. 从 [[Aspect 体 aspect|aspect]] 上看，它是**未完成体**（imperfective），与 [[Perfect 复合过去时 Passé composé|passé composé]] / [[Past historic 简单过去时 passé simple|passé simple]] 的完成体相对。

Its compound form is the [[Pluperfect 愈过去时 plus-que-parfait|pluperfect]].

# Formation

Almost all verbs conjugate according to the same rule (except a few cases):
the stem = the 1st person plural of the present indicative - "-ons"
the desinence =:

|              | stem | desinence |
| ------------ | ---- | --------- |
| 1st pers. s. | -    | -ais      |
| 2nd pers s.  | -    | -ais      |
| 3rd pers. s. | -    | -ait      |
| 1st pers. p. | -    | -ions     |
| 2nd pers p.  | -    | -iez      |
| 3rd pers. p. | -    | -aient    |

> nous **parl**ons → je parlais
> nous **finiss**ons → je finissais
> nous **vend**ons → je vendais
> nous **buv**ons → je buvais
> nous **fais**ons → je faisais

-ais, -ait, -aient 三者读音相同 [ɛ]。

## Regular verbs

|              | parler     | finir         | vendre     |
| ------------ | ---------- | ------------- | ---------- |
| 1st pers. s. | parlais    | finissais     | vendais    |
| 2nd pers s.  | parlais    | finissais     | vendais    |
| 3rd pers. s. | parlait    | finissait     | vendait    |
| 1st pers. p. | parlions   | finissions    | vendions   |
| 2nd pers p.  | parliez    | finissiez     | vendiez    |
| 3rd pers. p. | parlaient  | finissaient   | vendaient  |

## Irregular verbs

The only true exception is *être*, whose stem is **ét-**. *avoir, aller, faire* follow the rule.

|              | être     | avoir    | aller    | faire     |
| ------------ | -------- | -------- | -------- | --------- |
| 1st pers. s. | étais    | avais    | allais   | faisais   |
| 2nd pers s.  | étais    | avais    | allais   | faisais   |
| 3rd pers. s. | était    | avait    | allait   | faisait   |
| 1st pers. p. | étions   | avions   | allions  | faisions  |
| 2nd pers p.  | étiez    | aviez    | alliez   | faisiez   |
| 3rd pers. p. | étaient  | avaient  | allaient | faisaient |

Impersonal verbs: *il faut* → *il fallait*; *il pleut* → *il pleuvait*.

## Spelling changes

- Verbs in **-cer / -ger** keep the soft sound before *a*: *je commençais, je mangeais*, but *nous commencions, nous mangions*.
- Verbs whose stem ends in **-i** or **-y** have a double *i* / *yi* in the *nous/vous* forms: *nous étudiions, vous riiez, nous envoyions*.

# Use

## Description and background

> Il **faisait** beau, les enfants **jouaient** dans le jardin.
> -> The weather was fine, the children were playing in the garden.

## State of mind, physical state, age, time

> J'**avais** vingt ans et je **voulais** voyager.
> -> I was twenty and I wanted to travel.

## Habit or repetition in the past

> Tous les étés, nous **allions** à la mer.
> -> Every summer we used to go to the seaside.

## Action in progress interrupted by another action

The interrupted action is in the imperfect, the interrupting one in the passé composé (or passé simple).

> Je **lisais** quand le téléphone **a sonné**.
> -> I was reading when the phone rang.

## Other uses

1. After *si* (hypothesis), with the present conditional in the main clause:
> **Si** j'**avais** le temps, je viendrais.
> -> If I had time, I would come.
2. Suggestion with *si* (alone):
> **Si** on **allait** au cinéma ?
> -> How about going to the cinema?
3. Politeness (attenuation):
> Je **voulais** vous demander un service.
> -> I wanted to ask you a favour.
4. Reported speech: the present becomes the imperfect after a past main verb.
> Il a dit qu'il **était** fatigué.
5. *venir de* / *être en train de* in the past:
> Il **venait de** partir. -> He had just left.
> J'**étais en train de** dîner. -> I was having dinner.

# Imparfait vs passé composé

| imparfait                          | passé composé                       |
| ---------------------------------- | ----------------------------------- |
| 背景、描述（décor）                 | 事件、情节推进（action）              |
| 持续，无明确起止                    | 完成，有界限                          |
| 习惯性重复                          | 一次性或有限次数                      |
| 正在进行                            | 打断它的动作                          |

> Hier, il **pleuvait**. (description)
> Hier, il **a plu** toute la journée. (bounded event: *toute la journée* closes it)

> Quand j'étais petit, je **jouais** au tennis. (habit)
> L'année dernière, j'**ai joué** au tennis trois fois. (counted)

Changing the tense can change the meaning of some verbs:

> Je **savais**. -> I knew (state).
> J'**ai su**. -> I found out.
> Il **devait** partir. -> He was supposed to leave.
> Il **a dû** partir. -> He had to leave / he must have left.

# English equivalent

There is no single equivalent: *was/were -ing* (progressive), *used to / would* (habit), or the simple past for states (*I knew, it was*).
