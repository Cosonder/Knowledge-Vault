# Definition
**社会保险**（social insurance，法 assurance sociale）是国家通过立法强制实施、由用人单位和劳动者（有时加上政府财政）共同缴费形成基金，在劳动者遭遇年老、疾病、工伤、失业、生育等风险时提供基本收入保障或补偿的制度。它是社会保障（social security，法 sécurité sociale）体系的核心组成部分。

与商业保险（见 [[Insurance 保险 assurance|Insurance 保险]]）的区别：

| | 社会保险 | 商业保险 |
|---|---|---|
| 实施方式 | 强制（法定） | 自愿（合同） |
| 目的 | 基本保障、收入再分配 | 营利 |
| 缴费与给付 | 与收入挂钩，体现互助共济 | 按风险精算定价 |
| 主体 | 国家 / 社保机构 | 保险公司 |

# Types
中国的"五险"：
1. **养老保险**（pension / old-age insurance，法 assurance vieillesse）
2. **医疗保险**（health insurance，法 assurance maladie）
3. **失业保险**（unemployment insurance，法 assurance chômage）
4. **工伤保险**（work injury insurance，法 assurance accidents du travail）
5. **生育保险**（maternity insurance，现已与医疗保险合并实施）

"五险一金"中的"一金"指住房公积金（housing provident fund），不属于社会保险。

# Financing models
- **现收现付制**（pay-as-you-go, PAYG，法 répartition）：当期在职者缴费直接支付当期退休者待遇，体现代际转移，法国养老体系以此为主。
- **基金积累制**（fully funded，法 capitalisation）：个人缴费积累于个人账户，投资增值后用于本人养老。
- **部分积累制**：两者结合。中国城镇职工基本养老保险采用"社会统筹 + 个人账户"模式。

历史渊源：德国俾斯麦（Otto von Bismarck）于 1880 年代建立了世界上最早的现代社会保险制度（Bismarckian model），与英国以税收为基础、普遍覆盖的贝弗里奇模式（Beveridge model）并列为两大传统。

# Challenges
- 人口老龄化（population ageing）导致抚养比上升，现收现付制面临收支压力。
- 延迟退休、提高缴费、引入第二、三支柱（企业年金、个人养老金）等改革。
- 社保基金的投资运营：如中国全国社会保障基金理事会作为[[Institutional investor 机构投资者 investisseur institutionnel|机构投资者]]进行长期投资。
