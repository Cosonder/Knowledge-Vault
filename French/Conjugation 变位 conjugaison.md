# Definition

Conjugation（变位, *la conjugaison*）is the [[Inflection 屈折变化 flexion|inflection]] of verbs: the set of forms a verb takes according to [[Person 人称 personne|person]], number, [[Tense 时态 temps|tense]], [[Mood 语气 mode|mood]], [[Voice 语态 voix|voice]] and [[Aspect 体 aspect|aspect]].

A conjugated (finite) verb = **stem (radical)** + **ending (terminaison)**.
> parl- + -ons → nous **parlons**
> fin- + -iss- + -ons → nous **finissons**

The finite verb agrees with its subject in person and number (see [[Agreement 配合 accord|agreement]]).

# Classification

## The three groups (les trois groupes)

| Group      | Infinitive                                   | Present 1st pers. p.   | Share       | Examples                          |
| ---------- | -------------------------------------------- | ---------------------- | ----------- | --------------------------------- |
| 1er groupe | **-er** (except *aller*)                     | -ons                   | ~90%, productive | parler, aimer, manger        |
| 2e groupe  | **-ir**, present participle **-issant**      | -issons                | ~300 verbs  | finir, choisir, réussir           |
| 3e groupe  | all others: -ir (no -iss-), -oir, -re, *aller* | irregular            | closed class | partir, voir, prendre, aller     |

New verbs are created in the 1st group (*googler, tweeter*). The 3rd group contains the most frequent verbs (*être, avoir, aller, faire, pouvoir, vouloir, dire, venir*).

## Simple vs compound forms

- **simple forms** (temps simples): one word, stem + ending. *je parle, je parlais, je parlerai*.
- **compound forms** (temps composés): auxiliary *avoir/être* + [[Past participle 过去分词 Participe passé|past participle]]. *j'ai parlé, j'étais parti*.

See [[Tense 时态 temps|tense]] for the full correspondence. Choice of auxiliary: see [[Perfect 复合过去时 Passé composé|passé composé]] and [[Intransitive verbs 不及物动词 verbes intransitifs|intransitive verbs]]; all [[Pronominal verb 代动词 verbe pronominal|pronominal verbs]] use *être*.

# Paradigms

## Present indicative of the three groups

|              | parler (1er) | finir (2e)   | vendre (3e) |
| ------------ | ------------ | ------------ | ----------- |
| 1st pers. s. | je parle     | je finis     | je vends    |
| 2nd pers s.  | tu parles    | tu finis     | tu vends    |
| 3rd pers. s. | il parle     | il finit     | il vend     |
| 1st pers. p. | nous parlons | nous finissons | nous vendons |
| 2nd pers p.  | vous parlez  | vous finissez | vous vendez |
| 3rd pers. p. | ils parlent  | ils finissent | ils vendent |

Note: *parle, parles, parlent* are pronounced the same [paʁl]. 法语书面上区分的人称，口语里往往同音，所以主语代词不可省略（与西班牙语、意大利语不同）。Details: [[Present indicative 直陈式现在时 indicatif présent|present indicative]].

## Which stem?

| Form                    | Stem                                              | Example (*finir*, *boire*)      |
| ----------------------- | ------------------------------------------------- | ------------------------------- |
| [[Imperfect 未完成过去时 Imparfait\|imparfait]] | *nous* present minus *-ons* (only exception: *être* → *ét-*) | nous finiss-ons → je **finiss**ais; nous buv-ons → je **buv**ais |
| [[Simple future 简单将来时 futur simple|futur]], conditionnel | infinitive (drop final *-e* of *-re*) | je **finir**ai; je **boir**ai |
| subjonctif présent      | *ils* present minus *-ent* (je, tu, il, ils); *nous/vous* = imparfait forms | qu'il **finiss**e; qu'il **boiv**e, que nous **buv**ions |
| [[Present participle 现在分词 Participe présent\|participe présent]] | *nous* present stem + *-ant* | **finiss**ant, **buv**ant |
| imperative              | present tu/nous/vous, no subject (*-er* verbs drop *-s*) | parle, parlons, parlez |

Irregular futures to memorize: *être → ser-, avoir → aur-, aller → ir-, faire → fer-, venir → viendr-, voir → verr-, pouvoir → pourr-, vouloir → voudr-, savoir → saur-, devoir → devr-, falloir → faudr-*.

# Remarks

## Spelling changes in the 1st group

Regular in pronunciation, but spelling adjusts (see [[French orthography 法语正字法 orthographe française|French orthography]]):
- *-cer*: c → **ç** before a, o: nous commen**ç**ons.
- *-ger*: g → **ge** before a, o: nous man**ge**ons.
- *e/é* + consonant + *-er*: è before mute endings: je l**è**ve, j'esp**è**re (nous levons, espérons).
- *-eler/-eter*: double consonant or è: j'appe**ll**e, je je**tt**e; j'ach**è**te.
- *-yer*: y → i before mute e: je pa**i**e, j'envo**i**e.

## Boot verbs (verbes à deux radicaux)

Many 3rd-group verbs have one stem for je/tu/il/ils and another for nous/vous:
> je **viens**, ils **viennent** / nous **venons**
> je **bois**, ils **boivent** / nous **buvons**

## Non-finite forms

Not conjugated for person: [[Infinitive 不定式 Infinitif|infinitive]], [[Present participle 现在分词 Participe présent|present participle]] / gerund (*en parlant*), [[Past participle 过去分词 Participe passé|past participle]].
