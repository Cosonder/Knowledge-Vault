# Introduction

The simple future (*le futur simple*) is a simple tense of the indicative that places an action after the moment of speaking. Its compound form is the [[Future perfect 先将来时 futur antérieur|future perfect]].

# Formation

the simple future = the future stem + the endings

## Endings

The endings are the same for all verbs (they come historically from the present of *avoir*: *-ai, -as, -a, -(av)ons, -(av)ez, -ont*).

|              | stem | desinence |
| ------------ | ---- | --------- |
| 1st pers. s. | -    | -ai       |
| 2nd pers s.  | -    | -as       |
| 3rd pers. s. | -    | -a        |
| 1st pers. p. | -    | -ons      |
| 2nd pers p.  | -    | -ez       |
| 3rd pers. p. | -    | -ont      |

## Stem

- -er and -ir verbs: the whole infinitive (*parler-, finir-*).
- -re verbs: the infinitive minus final *-e* (*vendr-, prendr-*).
- The stem always ends in **-r**. 将来时词干一定以 r 结尾；条件式现在时用同一词干。

|              | parler      | finir       | vendre     |
| ------------ | ----------- | ----------- | ---------- |
| 1st pers. s. | parlerai    | finirai     | vendrai    |
| 2nd pers s.  | parleras    | finiras     | vendras    |
| 3rd pers. s. | parlera     | finira      | vendra     |
| 1st pers. p. | parlerons   | finirons    | vendrons   |
| 2nd pers p.  | parlerez    | finirez     | vendrez    |
| 3rd pers. p. | parleront   | finiront    | vendront   |

## Irregular stems

|              | être     | avoir    | aller    | faire    |
| ------------ | -------- | -------- | -------- | -------- |
| 1st pers. s. | serai    | aurai    | irai     | ferai    |
| 2nd pers s.  | seras    | auras    | iras     | feras    |
| 3rd pers. s. | sera     | aura     | ira      | fera     |
| 1st pers. p. | serons   | aurons   | irons    | ferons   |
| 2nd pers p.  | serez    | aurez    | irez     | ferez    |
| 3rd pers. p. | seront   | auront   | iront    | feront   |

Other irregular stems:

| infinitive | stem     | infinitive | stem      |
| ---------- | -------- | ---------- | --------- |
| pouvoir    | pourr-   | venir      | viendr-   |
| vouloir    | voudr-   | tenir      | tiendr-   |
| savoir     | saur-    | devoir     | devr-     |
| voir       | verr-    | envoyer    | enverr-   |
| courir     | courr-   | mourir     | mourr-    |
| falloir    | il faudra | pleuvoir  | il pleuvra |

## Spelling changes (-er verbs)

- *e* + consonant + *er*: *acheter → j'achèterai*, *appeler → j'appellerai*, *jeter → je jetterai*.
- *-yer*: *payer → je paierai* (or *payerai*), *nettoyer → je nettoierai*.
- *é* + consonant + *er*: *préférer → je préférerai* (modern spelling also *préfèrerai*).

# Use

## Future action or state

> Demain, il **fera** beau.
> -> Tomorrow the weather will be fine.

## Prediction, promise

> Je te **téléphonerai** ce soir.
> -> I'll call you tonight.

## Instruction, softened order

> Vous **prendrez** ce médicament deux fois par jour.
> -> You will take this medicine twice a day.

## After *quand, lorsque, dès que, aussitôt que, tant que*

French uses the future in a temporal clause referring to the future, where English uses the present.

> **Quand** tu **seras** à Paris, appelle-moi.
> -> When you are in Paris, call me.

But after *si* (condition), never the future: *Si tu **viens**, je **serai** content.*

## Attenuation, conjecture (rare)

> Ce **sera** le facteur. -> That'll be the postman.

# Futur simple vs futur proche

The *futur proche* (*aller* + [[Infinitive 不定式 infinitif|infinitive]]) is very common in speech.

| futur proche                                  | futur simple                               |
| --------------------------------------------- | ------------------------------------------ |
| linked to the present, intention, imminence   | more detached, neutral or formal           |
| *Attention, tu vas tomber !*                  | *Un jour, tu tomberas.*                    |
| *Je vais partir en juin.* (decided)           | *Je partirai en juin.* (plan, prediction)  |

# English equivalent

*will / shall* + verb; *be going to* for the futur proche.
