# Definition
**不动产**（real estate / real property，法 immobilier / biens immobiliers）指土地以及附着于土地、不能移动或移动后会损害其价值的财产，如建筑物、构筑物及其附属设施。与之相对的是**动产**（personal property / movables，法 biens meubles）。中国法律中，不动产物权以登记为公示方式（《民法典》物权编）。

# Classification
- **住宅**（residential）：公寓、独栋住宅。
- **商业**（commercial）：写字楼、零售商铺、酒店。
- **工业**（industrial）：厂房、仓储物流设施。
- **土地**（land）：未开发土地、农用地。
- 特殊用途：医院、学校、数据中心等。

# As an asset class
不动产是重要的实物[[Asset 资产 actif|资产]]和另类投资类别，收益来源为：
- **租金收入**（rental income）：衡量指标为租金收益率（rental yield）或资本化率（cap rate）：
  $$\text{Cap rate} = \frac{\text{年净营业收入 NOI}}{\text{物业价值}}$$
- **资本增值**（capital appreciation）。

投资方式：
- 直接持有物业
- 房地产投资信托（REITs，Real Estate Investment Trust；法 SIIC 为上市型，SCPI 为非上市型）：将不动产证券化，提高流动性
- 房地产基金、房地产企业[[Stock 股票 action|股票]]、抵押贷款支持证券（MBS）

# Characteristics
- 低流动性（illiquidity）、交易成本高（税费、中介费）。
- 异质性：每处物业位置、条件不同，"location, location, location"。
- 常使用较高[[Leverage 杠杆|杠杆]]（按揭贷款 mortgage，法 prêt immobilier）。
- 长期具有一定抗[[Inflation 通货膨胀 inflation|通胀]]属性，但对利率敏感。
- 风险案例：2007–2008 年美国次贷危机（subprime crisis）源于房地产抵押贷款的过度扩张。

# Example
一套价值 500 万元的公寓，年租金 15 万元，年持有成本 3 万元，则 NOI 为 12 万元，cap rate 为 $12/500 = 2.4\%$。若首付 30%（150 万元），房价上涨 10% 则权益回报约为 $50/150 \approx 33\%$（未计利息），体现杠杆的放大作用。
