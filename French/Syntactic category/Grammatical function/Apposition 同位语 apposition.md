# Definition

An apposition (*l'apposition*) is a word or group placed beside a noun or pronoun to give further information about it, and referring to the **same entity**. There is no verb between them: the relation is that of an implicit *être*.

> **Paris**, *capitale de la France*, attire des millions de touristes. (= Paris est la capitale de la France.)

# Types

| type                                      | punctuation              | example                                            |
| ----------------------------------------- | ------------------------ | -------------------------------------------------- |
| detached 独立同位语 *apposition détachée*   | commas, colon, dashes    | *Mon voisin, **un ancien professeur**, m'aide souvent.* |
| bound 紧密同位语 *apposition liée*          | none                     | *le roi **Louis XIV**, le poète **Victor Hugo**, mon ami **Pierre*** |
| bound with *de*                           | none                     | *la ville **de Paris**, le mois **de mai**, le titre **de docteur*** |

In *la ville de Paris*, *de* is an "empty" preposition: it carries no meaning, Paris **is** the city.

# Forms

| form                                    | example                                              |
| --------------------------------------- | ---------------------------------------------------- |
| noun phrase                             | *Victor Hugo, **l'auteur des Misérables**, …*        |
| adjective / participle (détachée)       | ***Épuisée**, Marie s'est couchée tôt.*              |
| [[Infinitive 不定式 infinitif\|infinitive]] | *Il n'a qu'un désir : **partir**.*               |
| clause                                  | *Je n'ai qu'un souhait : **que tu réussisses**.*     |
| apposed to a pronoun                    | ***Nous**, les Français, aimons le fromage.*         |

The detached adjective is also called [[Attributive adjective 定语 épithète|épithète détachée]]; grammars differ on the label.

# Position and punctuation

- A detached apposition can come after or before the noun; when fronted, the noun phrase usually drops its article: ***Ancien ministre**, il connaît bien le dossier.*
- Commas change the meaning: *mon frère Paul* (bound: I have several brothers, the one called Paul) vs *mon frère, Paul, …* (detached: my only brother, whose name is Paul). Compare the restrictive vs non-restrictive [[Relative pronoun 关系代词 pronom relatif|relative clause]].
- The colon introduces an apposition that sums up or explains: *Une seule chose compte : **la santé**.*

# Agreement

- A noun in apposition keeps its own gender and number: *Cette femme, **un génie** de la physique, …* · *Mes parents, **ma seule famille**, …*
- An adjective or participle in apposition agrees with the noun (see [[Agreement 配合 accord|agreement]]): ***Surprises**, les filles se sont tues.*
- Verb and participle agree with the head noun, not with the apposition: *Ma tante, **un médecin célèbre**, est parti**e** hier.*

# Apposition vs complément du nom

| test                       | apposition                             | [[Noun complement 名词补语 complément du nom\|complément du nom]] |
| -------------------------- | -------------------------------------- | ----------------------------------------- |
| identity                   | same entity: *la ville de Paris* (la ville = Paris) | different entity: *les rues de Paris* (rues ≠ Paris) |
| *être* paraphrase          | *Paris est une ville.* ✔               | *\*Paris est des rues.* ✘                 |
| deleting the head          | *Paris* alone still names the same thing | *Paris* alone changes the meaning       |

# Comparison with Chinese and English

- 汉语同位语多为紧密型，而且通常类别名在前、专名在后：首都北京、我的朋友小王 → *la capitale, Pékin* / *mon ami Xiao Wang*。法语紧密同位语 *la ville de Paris* 需要"空"介词 *de*，汉语只说"巴黎市"。
- 汉语较少用逗号隔开的独立同位语，常改为定语："法国首都巴黎"；法语偏爱 *Paris, capitale de la France, …*。
- English: *King Louis XIV* has no article; French needs one: *le roi Louis XIV*. Same with titles: *President Macron → le président Macron*.
