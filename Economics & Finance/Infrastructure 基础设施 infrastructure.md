# Definition
**基础设施**（infrastructure，法 infrastructure）指为社会生产和居民生活提供公共服务的物质工程设施和组织系统，是经济运行的基础。其典型特征为：投资规模大、建设周期长、使用寿命长、具有网络效应和一定的自然垄断（natural monopoly）或公共品（public good）属性。

# Classification
- **经济基础设施**（economic infrastructure，"硬"基础设施）：
  - 交通：公路、铁路、港口、机场
  - 能源：电网、发电站、油气管道
  - 公用事业（utilities）：供水、排水、燃气
  - 通信：电信网络、数据中心、5G 基站
- **社会基础设施**（social infrastructure）：学校、医院、公共住房、监狱等。
- 中国语境下另有"新基建"：5G、特高压、城际高铁、新能源汽车充电桩、大数据中心、人工智能、工业互联网等。

# As an asset class
在投资领域，基础设施是一类重要的另类资产（alternative asset，法 actif alternatif），属于实物[[Asset 资产 actif|资产]]：
- **收益特征**：现金流长期、稳定，常受特许经营协议或受监管定价保障，部分收入与[[Inflation 通货膨胀 inflation|通胀]]挂钩。
- **主要投资者**：养老金、主权财富基金、保险公司等[[Institutional investor 机构投资者 investisseur institutionnel|机构投资者]]，因其负债期限长，与基础设施的长久期相匹配。
- **投资方式**：直接投资、基础设施基金、上市基础设施公司股票、基础设施 REITs（中国自 2021 年推出公募基础设施 REITs）、项目债券。
- **融资模式**：政府财政投资、PPP（public-private partnership，政府与社会资本合作，法 partenariat public-privé）、BOT（建设-运营-移交）。

# Risks
- 建设风险（成本超支、延期）
- 政策与监管风险（定价、特许权变更）
- 流动性风险：资产难以快速转让
- 需求风险：如收费公路车流量低于预期
