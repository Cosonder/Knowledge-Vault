# Introduction

The object (*le complément d'objet*) is the complement required by the verb, on which the action bears. French grammar distinguishes two kinds, according to whether a preposition is present:

| type                                           | abbreviation | construction                 | example                          |
| ---------------------------------------------- | ------------ | ---------------------------- | -------------------------------- |
| direct object 直接宾语 *complément d'objet direct* | **COD**      | verb + object (no preposition) | J'aime **la musique**.         |
| indirect object 间接宾语 *complément d'objet indirect* | **COI** | verb + *à / de* + object     | Je parle **à Marie**. Je parle **de ce film**. |
| second object *complément d'objet second*      | **COS**      | COI of a verb that already has a COD | Je donne un livre **à Paul**. |

A verb with no object is [[Intransitive verbs 不及物动词 verbes intransitifs|intransitive]].

# How to identify COD and COI

- COD: answers *qui ? / quoi ?* directly after the verb: *J'aime quoi ? → la musique.*
- COI: answers *à qui ? à quoi ? de qui ? de quoi ?*: *Je parle à qui ? → à Marie.*
- Unlike circumstantial complements, objects generally cannot be moved or deleted freely.
- The COD becomes the subject in the passive; the COI cannot.

> Paul écrit **la lettre**. → **La lettre** est écrite par Paul.

# Pronouns for objects

The distinction is essential for choosing the [[Personal pronoun 人称代词 pronom personnel|personal pronoun]].

| object                               | pronoun                      | example                                 |
| ------------------------------------ | ---------------------------- | --------------------------------------- |
| COD (definite)                       | me, te, **le, la, les**, nous, vous | Je vois **Marie**. → Je **la** vois.   |
| COD (indefinite / partitive / number) | **en**                      | J'ai **des pommes**. → J'**en** ai.     |
| COI with *à* + person                | me, te, **lui, leur**, nous, vous | Je parle **à Marie**. → Je **lui** parle. |
| COI with *à* + thing                 | **y**                        | Je pense **à mon examen**. → J'**y** pense. |
| COI with *de* + thing                | **en**                       | Je parle **de ce film**. → J'**en** parle. |
| *à / de* + person with some verbs (*penser à, s'intéresser à, parler de*) | à / de + tonic pronoun | Je pense **à lui**. Je parle **d'elle**. |

# COD and agreement of the past participle

With *avoir*, the [[Past participle 过去分词 participe passé|past participle]] agrees with the **COD placed before the verb**; a COI never triggers agreement (see [[Perfect 复合过去时 passé composé|passé composé]] and [[Agreement 配合 accord|agreement]]).

> Je **l'**ai vu**e**. (COD *la* = Marie)
> Je **lui** ai parlé. (COI: no agreement)

# 法语与英语中宾语使用的比较

The two languages often disagree on whether a verb takes a direct or indirect object. 英语直接宾语 ≠ 法语直接宾语，需要逐个记忆。

## English direct, French indirect (COI)

| English                 | French                      |
| ----------------------- | --------------------------- |
| to obey sb              | obéir **à** qn              |
| to answer sb / sth      | répondre **à** qn / qch     |
| to phone sb             | téléphoner **à** qn         |
| to resemble sb          | ressembler **à** qn         |
| to please sb            | plaire **à** qn             |
| to trust sb             | faire confiance **à** qn    |
| to use sth              | se servir **de** qch        |
| to need sth             | avoir besoin **de** qch     |
| to remember sth         | se souvenir **de** qch      |
| to change sth (trains…) | changer **de** train        |

> Il **obéit à** ses parents. → Il **leur** obéit.

## English prepositional, French direct (COD)

| English                 | French              |
| ----------------------- | ------------------- |
| to look **for** sth     | chercher qch        |
| to look **at** sth      | regarder qch        |
| to wait **for** sb      | attendre qn         |
| to listen **to** sth    | écouter qch         |
| to ask **for** sth      | demander qch        |
| to pay **for** sth      | payer qch           |

> J'**attends** le bus. → Je **l'**attends.
> -> I'm waiting for the bus.

## Double-object verbs

English allows *give sb sth*; French never puts two bare objects together: the person is always a COI with *à*.

> I gave **Paul** the book. → J'ai donné le livre **à Paul**. → Je **le lui** ai donné.

## Passive

English can passivize the indirect object (*He was given a book*); French cannot. French uses *on*:

> **On lui** a donné un livre.
> -> He was given a book.
