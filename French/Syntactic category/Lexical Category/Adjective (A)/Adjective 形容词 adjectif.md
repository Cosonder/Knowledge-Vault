# 综述

The adjective (*l'adjectif*) modifies a noun or pronoun. Traditional French grammar distinguishes two kinds:

| kind | French term | role | example |
| ---- | ----------- | ---- | ------- |
| qualifying adjective 品质形容词 | *adjectif qualificatif* | describes a quality | une maison **blanche** |
| determinative adjective 限定形容词 | *adjectif déterminatif* (possessive, demonstrative, interrogative, numeral, indefinite) | introduces the noun | **cette** maison, **ma** maison |

Modern grammar calls the second group [[Determiner 限定词 déterminant|determiners]]; this note deals with qualifying adjectives. 形容词必须与所修饰的名词在 [[Gender of nouns 名词的性 genre des noms|gender]] 和 [[Number of nouns 名词的数 nombre des noms|number]] 上 [[Agreement 配合 accord|agree]]。

# Feminine formation

General rule: masculine + **-e** (*grand → grande, joli → jolie*). Adjectives already ending in *-e* do not change (*rouge, facile, jeune*).

| masculine | feminine | examples |
| --------- | -------- | -------- |
| -eux | **-euse** | heureux → heureuse, sérieux → sérieuse |
| -if | **-ive** | actif → active, sportif → sportive, neuf → neuve |
| -er | **-ère** | cher → chère, premier → première, léger → légère |
| -el, -eil | **-elle, -eille** | cruel → cruelle, naturel → naturelle, pareil → pareille |
| -en, -on | **-enne, -onne** | ancien → ancienne, bon → bonne |
| -et | **-ette** | muet → muette (but complet → complète, inquiet → inquiète, secret → secrète) |
| -eur | **-euse** / **-trice** / **-eure** | menteur → menteuse, créateur → créatrice, meilleur → meilleure |
| -c | **-che** / **-que** | blanc → blanche, sec → sèche, franc → franche; public → publique, grec → grecque |
| -g | **-gue** | long → longue |
| -x | **-se** / **-ce** | faux → fausse, roux → rousse, doux → douce |

Irregular: *frais → fraîche, gentil → gentille, nul → nulle, favori → favorite, fou → folle, mou → molle*.

## Adjectives with a second masculine form

Before a masculine noun beginning with a vowel or h muet, five adjectives use a special form (to allow [[Liaison 联诵 liaison|liaison]] / enchaînement):

| masc. | masc. before vowel | fem. | example |
| ----- | ------------------ | ---- | ------- |
| beau | **bel** | belle | un **bel** homme, une **belle** femme |
| nouveau | **nouvel** | nouvelle | un **nouvel** appartement |
| vieux | **vieil** | vieille | un **vieil** ami |
| fou | **fol** | folle | un **fol** espoir |
| mou | **mol** | molle | un **mol** oreiller |

Plural masculine always uses the normal form: *de **beaux** hommes, de **vieux** amis*.

# Plural formation

General rule: + **-s** (*petit → petits*); adjectives in *-s / -x* are invariable in the masculine plural (*gris, heureux*).

| singular | plural | examples | exceptions |
| -------- | ------ | -------- | ---------- |
| -eau | **-eaux** | beau → beaux, nouveau → nouveaux | — |
| -al | **-aux** | national → nationaux, égal → égaux | banal, bancal, fatal, final, natal, naval → **-als**; idéal → idéals / idéaux |
| -eu | + s | bleu → bleus | hébreu → hébreux |

The feminine plural is always regular: *nationales, belles, finales*.

# Colour adjectives

- Simple colour adjectives agree: *des robes **vertes***.
- Compound colours are **invariable**: *des yeux **bleu clair***, *une veste **vert foncé***, *des chemises **bleu-vert***.
- Colours derived from nouns are **invariable**: *des chaussures **marron***, *des pulls **orange***, *des robes **cerise***.
- Exceptions that agree: *rose, mauve, pourpre, fauve, écarlate*: *des fleurs **roses***.

Other invariables: *chic* (usually), *demi* before the noun (*une **demi**-heure*, but *deux heures et **demie***), *nu* before the noun (*nu-pieds*, but *pieds **nus***).

# Position

Most adjectives follow the noun (*un livre **intéressant***); a group of short, frequent ones precede it (BAGS: beauty, age, goodness, size: *beau, jeune, vieux, bon, mauvais, grand, petit…*). Some change meaning with position (*un **grand** homme* / *un homme **grand***). See [[Attributive adjective 定语 épithète|épithète]] for details.

# Comparative and superlative

| degree | construction | example |
| ------ | ------------ | ------- |
| superiority | **plus** + adj. + **que** | Elle est **plus** grande **que** son frère. |
| equality | **aussi** + adj. + **que** | Il est **aussi** intelligent **que** toi. |
| inferiority | **moins** + adj. + **que** | Ce film est **moins** long **que** l'autre. |
| superlative | **le / la / les plus (moins)** + adj. | C'est **la plus** belle ville. |

When the adjective follows the noun, the article is repeated: *le film **le plus** intéressant*. See [[plus 更多 plus|plus]].

Irregular forms:

| adjective | comparative | superlative |
| --------- | ----------- | ----------- |
| bon | **meilleur** (✗ plus bon) | le meilleur |
| mauvais | plus mauvais / **pire** | le plus mauvais / **le pire** |
| petit | plus petit (size) / **moindre** (abstract) | le plus petit / **le moindre** |

> C'est **le meilleur** restaurant de la ville.
> Je n'en ai pas **la moindre** idée. -> I haven't the slightest idea.

注意：*meilleur* 是形容词，*mieux* 是副词（见 [[Adverb 副词 adverbe|adverb]]）。

# Functions

| function | French term | example |
| -------- | ----------- | ------- |
| attributive 定语 | [[Attributive adjective 定语 épithète\|épithète]] | une **belle** maison |
| predicative 表语 | [[Predicative complement 表语 attribut\|attribut]] | La maison est **belle**. Je la trouve **belle**. |
| appositive 同位语 | [[Apposition 同位语 apposition\|apposition]] | **Fatiguée**, elle s'est couchée tôt. |

An adjective can also take its own complement, usually with *à* or *de*: *content **de** son travail*, *prêt **à** partir* (see [[Preposition 介词 préposition|preposition]]).
