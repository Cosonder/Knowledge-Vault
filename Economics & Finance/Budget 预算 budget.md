# Definition
**预算**（budget，法 budget）是对未来一定时期内收入与支出的计划安排，以货币形式表达，用于资源分配、控制和绩效评估。该词经由英语来自古法语 bougette（小钱袋）。根据主体不同，可分为个人/家庭预算、企业预算和政府（财政）预算。

# Types
## Personal budget
个人/家庭预算是[[Personal finance 个人理财 finances personnelles|个人理财]]的基础，核心是规划收入在消费、储蓄与[[Investment 投资 investissement|投资]]之间的分配。常见方法：
- **50/30/20 法则**：税后收入的 50% 用于必要支出（needs），30% 用于可选支出（wants），20% 用于储蓄与偿债（savings）。
- **零基预算**（zero-based budgeting）：每一元收入都被分配到某个用途，收入 − 支出 − 储蓄 = 0。
- **先储蓄后消费**（pay yourself first）：收入到账即划转固定比例储蓄，可与[[Dollar cost averaging 平均成本法 investissement programmé|定投]]结合。

## Corporate budget
企业预算属于[[Financial management 财务管理 gestion financière|财务管理]]与管理会计的范畴：
- 经营预算（operating budget）：销售、生产、费用预算。
- 资本预算（capital budgeting）：长期投资项目评估，常用净现值（NPV）、内部收益率（IRR）等方法。
- 现金预算（cash budget）、预计财务报表。
- 方法：增量预算、零基预算、滚动预算（rolling budget）、弹性预算（flexible budget）。
- **预算差异分析**（variance analysis）：比较实际与预算，找出偏差原因。

## Government budget
政府预算（public / state budget，法 budget de l'État / loi de finances）是经立法机关批准的年度财政收支计划。
- 财政收入 > 支出：预算盈余（budget surplus）
- 财政收入 < 支出：预算赤字（budget deficit，法 déficit budgétaire），通常通过发行国债弥补
- 赤字率 = 财政赤字 / GDP；欧盟《稳定与增长公约》设定 3% 的参考上限。

# Example
月税后收入 10000 元，按 50/30/20 法则：必要支出 5000 元，可选支出 3000 元，储蓄投资 2000 元。
