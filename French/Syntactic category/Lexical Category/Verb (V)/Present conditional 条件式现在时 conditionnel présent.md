# Introduction

The present conditional (*le conditionnel présent*) presents a process as dependent on a condition, as uncertain, or as softened. Traditional grammar treats it as a separate [[Mood 语气 mode|mood]]; many modern grammars count it as a [[Tense 时态 temps|tense]] of the indicative ("futur du passé"). 形式上它 = 将来时词干 + 未完成过去时词尾，两种看法都由此而来。Its compound form is the conditionnel passé.

# Formation

the present conditional = the [[Simple future 简单将来时 futur simple|futur simple]] stem + the [[Imperfect 未完成过去时 imparfait|imparfait]] endings

|              | stem | desinence |
| ------------ | ---- | --------- |
| 1st pers. s. | -r-  | -ais      |
| 2nd pers s.  | -r-  | -ais      |
| 3rd pers. s. | -r-  | -ait      |
| 1st pers. p. | -r-  | -ions     |
| 2nd pers p.  | -r-  | -iez      |
| 3rd pers. p. | -r-  | -aient    |

## Regular verbs

|              | parler       | finir       | vendre      |
| ------------ | ------------ | ----------- | ----------- |
| 1st pers. s. | parlerais    | finirais    | vendrais    |
| 2nd pers s.  | parlerais    | finirais    | vendrais    |
| 3rd pers. s. | parlerait    | finirait    | vendrait    |
| 1st pers. p. | parlerions   | finirions   | vendrions   |
| 2nd pers p.  | parleriez    | finiriez    | vendriez    |
| 3rd pers. p. | parleraient  | finiraient  | vendraient  |

## Irregular stems

The irregular stems are exactly those of the futur simple.

|              | être      | avoir     | aller     | faire     |
| ------------ | --------- | --------- | --------- | --------- |
| 1st pers. s. | serais    | aurais    | irais     | ferais    |
| 2nd pers s.  | serais    | aurais    | irais     | ferais    |
| 3rd pers. s. | serait    | aurait    | irait     | ferait    |
| 1st pers. p. | serions   | aurions   | irions    | ferions   |
| 2nd pers p.  | seriez    | auriez    | iriez     | feriez    |
| 3rd pers. p. | seraient  | auraient  | iraient   | feraient  |

| infinitive | stem    | infinitive | stem     |
| ---------- | ------- | ---------- | -------- |
| pouvoir    | pourr-  | venir      | viendr-  |
| savoir     | saur-   | voir       | verr-    |
| vouloir    | voudr-  | envoyer    | enverr-  |
| devoir     | devr-   | courir     | courr-   |
| falloir    | faudr-  | mourir     | mourr-   |

Spelling changes as in the future: *j'achèterais, j'appellerais, je paierais*.

## *-rai* vs *-rais*

| futur simple        | conditionnel présent  |
| ------------------- | --------------------- |
| je parlerai [ʁe]    | je parlerais [ʁɛ]     |
| j'irai, je saurai   | j'irais, je saurais   |

只有第一人称单数容易混淆：标准发音 *-rai* 为闭口 [e]，*-rais* 为开口 [ɛ]，但很多说话人已不区分。书写时用替换法：换成 *nous*（*nous parlerons* → futur; *nous parlerions* → conditionnel）。

# Use

## Hypothesis: *si* + imparfait → conditionnel

> **Si** j'avais le temps, je **viendrais**.
> -> If I had time, I would come.

The *si* clause can also be replaced by *au cas où* + conditional, *à ta place*, *sans*, etc.:

> À ta place, je **partirais**. Au cas où il **pleuvrait**, prends un parapluie.

**Never after *si* of condition**: ❌ *Si j'aurais le temps* → *Si j'avais le temps*. (After *si* = "whether", in an indirect question, the conditional is fine: *Je me demande s'il **viendrait**.*)

## Politeness, attenuation

> Je **voudrais** un café, s'il vous plaît.
> **Pourriez**-vous m'aider ? **Auriez**-vous l'heure ?

## Advice, suggestion

> Tu **devrais** te reposer. On **pourrait** aller au cinéma.

## Unconfirmed information (journalism)

> Le président **serait** malade.
> -> The president is reportedly ill. 新闻用语："据说"，记者不为消息负责。

## Imagination, games

> On **dirait** un château. Toi, tu **serais** le roi.

## Future in the past

In reported speech after a past main verb, the futur becomes the conditional:

> Il dit qu'il **viendra**. → Il a dit qu'il **viendrait**.
> -> He said he would come.

# Conditionnel passé

conditional of *avoir / être* + [[Past participle 过去分词 participe passé|past participle]]: unreal past, regret, reproach.

> Si j'avais eu le temps, je **serais venu**.
> J'**aurais dû** te le dire. -> I should have told you.

# English equivalent

*would* / *should* + verb; *could* (*pourrais*), *should* (*devrais*), *reportedly / allegedly* for the journalistic use.
