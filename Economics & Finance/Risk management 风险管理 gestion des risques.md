# Definition

**风险管理**（risk management, *gestion des risques*）是识别、度量、评估并控制不确定性对目标所造成影响的系统过程。在金融中，它指金融机构、企业或个人对各类 [[Financial risks 金融风险 risques financiers|金融风险]] 进行管理，使承担的风险与收益目标和风险承受能力相匹配。

风险管理的目标不是消除风险——没有风险就没有收益——而是**有意识地选择承担哪些风险、承担多少**。

# Process

1. **风险识别**（identification）：列出可能面临的风险。
2. **风险度量**（measurement）：量化风险大小，如波动率、[[VaR 风险价值 valeur en risque|VaR]]（风险价值）、[[Stress test 压力测试 test de résistance|压力测试]]、情景分析。
3. **风险应对**（treatment），常见四种策略：
   - **规避**（avoid）：不从事该活动；
   - **降低**（reduce）：分散化（diversification）、止损、内部控制；
   - **转移**（transfer）：购买[[Insurance 保险 assurance|保险]]、用[[Derivative 金融衍生品 produit dérivé|衍生品]][[Hedge 对冲 couverture|对冲]]；
   - **接受**（accept / retain）：风险较小或成本过高时自留。
4. **监控与报告**（monitoring）：持续跟踪风险敞口，设定限额（limits）。

# Classification of financial risks

- **市场风险**（market risk）：价格、利率、汇率、商品价格变动带来的损失。
- **信用风险**（credit risk）：交易对手违约。
- **流动性风险**（liquidity risk）：无法以合理价格及时变现或融资。
- **操作风险**（operational risk）：内部流程、人员、系统失误或外部事件。
- **系统性风险**（systemic risk）：整个金融体系连锁崩溃的风险。

# Example

一个 100 万元的[[Portfolio 投资组合 portefeuille|投资组合]]，若测得 1 天 99% 置信度的 VaR 为 2 万元，意味着在正常市场条件下，一天内损失超过 2 万元的概率约为 1%。管理者可据此设定限额，若 VaR 超过 3 万元则减仓。
