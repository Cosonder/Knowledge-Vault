# Overview

**佛教**（Buddhism, *bouddhisme*）是公元前 6—前 5 世纪由古印度释迦族王子乔达摩·悉达多（Siddhārtha Gautama）创立的宗教与哲学传统。他在菩提树下觉悟后被称为**佛陀**（Buddha，"觉者"）。"佛"的本义不是神，而是"醒过来的人"。

佛教关心的核心问题是：**人为什么会苦，以及如何从苦中解脱**。与其说它提供一套关于世界起源的教义，不如说它是一种对心的观察方法和一条实践道路。

# Core ideas

**四圣谛**（Four Noble Truths, *quatre nobles vérités*）——佛陀初转法轮的内容，结构类似医学诊断：

1. **苦谛**（duḥkha）：生命中普遍存在不满足、不安与痛苦；
2. **集谛**（samudaya）：苦的根源是贪爱（taṇhā，渴求）与无明；
3. **灭谛**（nirodha）：苦可以止息，其境界称为**涅槃**（nirvāṇa）；
4. **道谛**（mārga）：止息苦的方法是**八正道**——正见、正思维、正语、正业、正命、正精进、正念、正定，可归纳为**戒、定、慧**三学。

**三法印**（Three Marks of Existence）：

- **诸行无常**（anicca, impermanence）：一切现象都在变化；
- **诸法无我**（anattā, non-self）：不存在一个恒常、独立的"自我"实体，"我"是五蕴（色、受、想、行、识）暂时的聚合；
- **涅槃寂静**（nirvāṇa as peace）；南传佛教的"三相"则以**苦**（dukkha）代替此项。

**缘起**（pratītyasamutpāda, dependent origination）："此有故彼有，此生故彼生"。万物没有独立自存的本质，皆依条件而生灭。大乘佛教由此发展出**空**（śūnyatā, emptiness）的思想，空不是"什么都没有"，而是"没有自性"。

**业与轮回**（karma, saṃsāra）：有意的行为会产生相应的果报，推动生死流转；解脱即跳出轮回。

**中道**（middle way）：佛陀在经历纵欲与苦行两种极端后，主张两者都不能导向觉悟。

# Schools

- **上座部佛教**（Theravāda）：流行于斯里兰卡、泰国、缅甸等地，重视个人修行与巴利语经典，理想人格是阿罗汉（arhat）。
- **大乘佛教**（Mahāyāna）：流行于中国、日本、韩国、越南，强调普度众生的**菩萨**（bodhisattva）理想，以及空性与佛性思想。其中国化的宗派包括天台、华严、净土和**禅宗**（Chan / Zen）。
- **金刚乘 / 藏传佛教**（Vajrayāna）：流行于西藏、蒙古，融合密教修法。

禅宗主张"不立文字，教外别传，直指人心，见性成佛"。六祖惠能的"何期自性，本自具足"代表了如来藏 / 佛性思想：觉悟不是向外获得什么，而是去除遮蔽、认出本来就有的东西，见 [[本自具足]]。这一思想也影响了宋明儒家的心学。

# Key figures

- **释迦牟尼**（Śākyamuni）：佛教创始人；
- **龙树**（Nāgārjuna，约 2 世纪）：中观学派（Madhyamaka），系统阐述"空"；
- **世亲、无著**（Vasubandhu, Asaṅga）：唯识学派（Yogācāra）；
- **鸠摩罗什、玄奘**：重要的佛经汉译者；
- **惠能**（638—713）：禅宗六祖，《六祖坛经》。

# Reflection

佛教与希腊化时代的哲学有可比之处：[[Stoicism 斯多葛主义 stoïcisme|斯多葛主义]]同样认为痛苦主要来自我们对外物的判断和执着，而非外物本身；两者都把哲学当作一种治疗灵魂的实践。不同在于，斯多葛派相信理性的宇宙秩序（logos）和一个应当按理性生活的自我，而佛教则进一步质疑那个"自我"本身。
