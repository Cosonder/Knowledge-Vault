# Definition
**资产**（asset，法 actif）是由过去的交易或事项形成、由主体拥有或控制、预期会带来未来经济利益的资源。在会计中，资产列示于资产负债表（balance sheet，法 bilan）的左侧（借方），满足会计恒等式：

$$\text{资产} = \text{负债} + \text{所有者权益}$$

即 Assets = Liabilities + Equity（法 actif = passif + capitaux propres）。

# Classification
- **按流动性**：
  - 流动资产（current assets，法 actif circulant）：一年或一个营业周期内可变现，如现金、应收账款、存货。
  - 非流动资产（non-current assets，法 actif immobilisé）：如厂房设备、长期股权投资。
- **按形态**：
  - 有形资产（[[Tangible asset 有形资产 actif corporel|tangible asset]]）：土地、建筑、机器、[[Commodity 商品 matière première|大宗商品]]。
  - 无形资产（intangible asset）：专利、商标、商誉（goodwill）。
- **按性质（金融视角）**：
  - 实物资产（real asset）：[[Real estate 不动产 immobilier|不动产]]、[[Infrastructure 基础设施 infrastructure|基础设施]]、黄金等。
  - 金融资产（financial asset）：对未来现金流的合约性索取权，如[[Stock 股票 action|股票]]、债券、[[Fund 基金 fonds|基金]]份额、[[Derivative 金融衍生品 produit dérivé|衍生品]]。一方的金融资产必然对应另一方的负债或权益。
- **资产类别**（asset class）：投资中常按风险收益特征划分为股票、固定收益、现金、商品、不动产、另类资产等，是资产配置（asset allocation）和[[Portfolio 投资组合 portefeuille|投资组合]]构建的基本单位。

# Valuation
资产的价值通常可按以下方式衡量：
- 历史成本（historical cost）：取得时支付的金额。
- 公允价值（fair value）：当前市场条件下有序交易的价格。
- 现值（present value）：未来现金流按折现率 $r$ 折现之和：

$$PV = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}$$

# Example
某公司持有现金 100 万元、存货 50 万元、设备 350 万元，资产总计 500 万元；若银行借款 200 万元，则所有者权益为 $500 - 200 = 300$ 万元。
