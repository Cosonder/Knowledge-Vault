## Conventions

- **File names:** `English term 中文 terme français.md`. Proper nouns or notes without a natural French term may omit it.
- **Frontmatter:** every note has `aliases` (English, and ideally Chinese and French forms) so links resolve by any of the three names; newer notes also carry a one-line `summary`.
- **Sections:** structured notes typically use `# Definition`, `# Classification` / `# Examples`, `# Remarks`, and `# Related`.
- **Links:** use `[[Note|alias]]`; inside tables escape the pipe as `[[Note\|alias]]` or the table breaks.
- **Math:** LaTeX in `$…$` / `$$…$$`; avoid custom macros (Obsidian's MathJax does not know them).
- `French/Meta.md` holds the person × number table template used in conjugation notes.
