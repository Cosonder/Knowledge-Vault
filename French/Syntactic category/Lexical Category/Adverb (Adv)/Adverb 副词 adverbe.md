# 综述

The adverb (*l'adverbe*) is an **invariable** word that modifies a verb, an adjective, another adverb or a whole sentence. 副词没有性数变化（*tout* 除外），在句中常作 [[Adverbial 状语 complément circonstanciel|状语]]。

> Il parle **lentement**. (verb) · Elle est **très** belle. (adjective) · Il court **trop** vite. (adverb) · **Heureusement**, il est venu. (sentence)

# Types

| type | French term | examples |
| ---- | ----------- | -------- |
| manner 方式 | *adverbes de manière* | bien, mal, vite, ainsi, ensemble, lentement |
| time 时间 | *de temps* | hier, aujourd'hui, demain, déjà, encore, souvent, toujours, jamais, bientôt, tôt, tard |
| place 地点 | *de lieu* | ici, là, là-bas, ailleurs, partout, dedans, dehors, loin, près |
| quantity / degree 数量·程度 | *de quantité / d'intensité* | très, trop, assez, peu, beaucoup, tellement, si, presque, plutôt |
| affirmation 肯定 | *d'affirmation* | oui, si, certes, vraiment, assurément |
| negation 否定 | *de négation* | non, ne … pas, ne … jamais, ne … plus (see [[Negation 否定 négation\|negation]]) |
| doubt 怀疑 | *de doute* | peut-être, probablement, sans doute |
| interrogative 疑问 | *interrogatifs* | où, quand, comment, pourquoi, combien (see [[Interrogative structure 疑问结构 structure interrogative\|questions]]) |

*si* answers a negative question: *Tu ne viens pas ? — **Si** !*

# Formation in -ment

| rule | examples |
| ---- | -------- |
| feminine adjective + **-ment** | lent → lente → lent**ement**, heureux → heureuse**ment**, doux → douce**ment**, actif → active**ment** |
| masculine ending in a vowel: masc. + **-ment** | vrai → vrai**ment**, poli → poli**ment**, absolu → absolu**ment**, aisé → aisé**ment** |
| **-ant → -amment** | constant → const**amment**, courant → cour**amment**, suffisant → suffis**amment** |
| **-ent → -emment** | évident → évid**emment**, prudent → prud**emment**, récent → réc**emment** |
| **-ément** (é added) | précis → précis**ément**, énorme → énorm**ément**, profond → profond**ément**, intense → intens**ément**, aveugle → aveugl**ément**, commun → commun**ément** |

- *-amment* and *-emment* are both pronounced [amɑ̃].
- Exceptions: *gentil → **gentiment***, *gai → gaiement*, *bref → **brièvement***, *lent → lentement* and *présent → présentement* (not ✗ -emment).
- Irregular adverbs not in *-ment*: *bon → **bien***, *mauvais → **mal***, *meilleur → **mieux***.

# Invariability and *tout*

Adverbs never agree, with one exception: *tout* (= "quite, completely") agrees before a **feminine** adjective beginning with a consonant or h aspiré.

> Ils sont **tout** contents. · Elle est **tout** heureuse. (h muet: invariable)
> Elle est **toute** contente. · Elles sont **toutes** honteuses. (agreement)

See [[Indefinite words 泛指词 mots indéfinis|indefinite words]] for the other uses of *tout*.

# Position

| context | position | example |
| ------- | -------- | ------- |
| simple tense | after the verb | Il parle **bien**. Je mange **souvent** ici. |
| compound tense, short adverbs (*bien, mal, déjà, encore, toujours, beaucoup, trop, vite*) | between auxiliary and participle | J'ai **bien** mangé. Il a **déjà** fini. |
| compound tense, adverbs of precise time/place | after the participle | Je suis arrivé **hier**. Il est allé **là-bas**. |
| long *-ment* adverbs | usually after the participle | Il a parlé **lentement**. |
| infinitive | usually before the infinitive | Il faut **bien** manger. pour **mieux** comprendre |
| modifying an adjective / adverb | before it | **très** beau, **trop** vite |
| sentence adverb | beginning, set off by a comma | **Malheureusement**, il pleut. |

与英语不同：法语副词不能放在主语与动词之间。✗ *Je souvent mange ici.* → *Je mange **souvent** ici.* (I often eat here.)

# Comparison

Adverbs use *plus / aussi / moins … que* like [[Adjective 形容词 adjectif|adjectives]]: *Il court **plus vite que** moi.* The superlative article is always **le** (invariable): *C'est elle qui court **le plus** vite.*

| adverb | comparative | superlative |
| ------ | ----------- | ----------- |
| bien | **mieux** (✗ plus bien) | le mieux |
| mal | **plus mal** / pis (literary) | le plus mal / le pis |
| beaucoup | **plus** / davantage | le plus |
| peu | **moins** | le moins |

*pis* survives in fixed expressions: *tant **pis***, *de mal en **pis***. See [[plus 更多 plus|plus]].

> Elle chante **mieux** que moi. (adverb) ≠ Sa voix est **meilleure**. (adjective)

# Adjectives used adverbially

Some adjectives act as adverbs after certain verbs and are then **invariable**:

> parler **fort**, coûter **cher**, sentir **bon / mauvais**, chanter **faux**, travailler **dur**, voir **clair**, s'arrêter **net**, marcher **droit**

> Ces roses sentent **bon**. (✗ bonnes) · Ces livres coûtent **cher**. (✗ chers)
