# Definition

The agent complement (*le complément d'agent*) names who or what performs the action in a passive sentence (see [[Voice 语态 voix|voice]]). It corresponds to the [[Subject 主语 sujet|subject]] of the active sentence, while the active COD becomes the passive subject (see [[Object 宾语 objet|object]]).

> **Le chat** mange la souris. → La souris est mangée **par le chat**.
> active subject → complément d'agent; active COD → passive subject

Structure: *être* (conjugated) + [[Past participle 过去分词 participe passé|past participle]] (agreeing with the subject) + ***par / de*** + agent.

# *par* or *de*

| preposition | used with                                                  | example                                              |
| ----------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| ***par***   | the general case, concrete actions                         | *La maison a été construite **par mon grand-père**.* |
| ***de***    | verbs of feeling 情感: *aimer, détester, haïr, respecter, admirer, craindre, estimer* | *Il est aimé **de tous**. Elle est respectée **de ses collègues**.* |
| ***de***    | verbs of state or description 状态 (often figurative): *couvrir, entourer, remplir, orner, composer, accompagner, suivre, précéder, connaître* | *La montagne est couverte **de neige**. Le jardin est entouré **d'arbres**.* |

The same verb can take *par* (a real action, an agent acting) or *de* (a resulting state):

> Le toit a été couvert **par les ouvriers**. (action) / Le toit est couvert **de neige**. (state)
> Le ministre est accompagné **de sa femme**. / Le ministre est accompagné **par la police**.

With *de*, the usual contractions apply, and *de* + *des* becomes *de* (no partitive article): *aimé **du** peuple, couvert **de** feuilles* (not *\*des feuilles*).

# Omission

The agent is omitted in most passive sentences: when it is unknown, obvious or unimportant.

> La porte a été fermée. Le voleur a été arrêté.

An active subject ***on*** never becomes an agent: *On a volé ma voiture.* → *Ma voiture a été volée.* (not *\*par on*). Conversely French often prefers *on* to a passive without agent.

# Other constructions with an agent

- Participle used alone: *une lettre écrite **par Victor Hugo***.
- Factitive *faire* + infinitive: *Il a fait construire sa maison **par un architecte**.*
- *se faire* + infinitive (often adversative): *Il s'est fait renverser **par une voiture**.*
- *se laisser* + infinitive: *Elle s'est laissé convaincre **par ses amis**.*
- The pronominal passive (*Ce livre se vend bien*) normally takes **no** agent.

# How to identify

1. The sentence is passive (*être* + participle with an action meaning).
2. Turn it into the active: the agent becomes the subject: *Il est aimé **de tous**.* → ***Tous** l'aiment.*
3. A pronoun agent is a tonic pronoun after the preposition: *par **lui**, d'**elle***; it is never a clitic.

Do not confuse with a [[Adverbial 状语 complément circonstanciel|complément circonstanciel]] introduced by *par*: *Il est passé **par la fenêtre*** (place: no passive, no active subject).

# Comparison with Chinese and English

- 汉语用"被 / 叫 / 让 + 施事"放在动词**前**：他被老师批评了 → *Il a été critiqué **par le professeur***。法语施事补语在动词**后**。
- 汉语语法中"被"后的施事是介词宾语，整个"被"字短语是状语，并没有"施事补语"这一独立成分。
- 汉语"被"字句常带不如意色彩；法语被动语态是中性的。
- 汉语可省略施事而只留"被"（他被打了 → *Il a été battu*）；法语同样可省略 *par*-短语。
- English uses only *by*; French distinguishes *par* and *de*: *loved by all → aimé **de** tous*, *covered with snow → couvert **de** neige*.
