# Introduction

The present subjunctive (*le subjonctif présent*) is the main tense of the subjunctive [[Mood 语气 mode|mood]]. The process is not asserted as a fact but seen through will, feeling, doubt or necessity. 虚拟式几乎总出现在 *que* 引导的从句中；它的"现在时"并不表示现在，而是相对于主句的同时或之后（[[Tense 时态 temps|tense]] 在虚拟式中只区分完成/未完成）。Its compound form is the subjonctif passé.

# Formation

## Stem and endings

the stem = the 3rd person plural of the [[Present indicative 直陈式现在时 indicatif présent|present indicative]] - "-ent"; *nous / vous* = the [[Imperfect 未完成过去时 imparfait|imparfait]] forms (stem of *nous* present).

> ils **parl**ent → que je parle
> ils **finiss**ent → que je finisse
> ils **vienn**ent → que je vienne, but nous **ven**ons → que nous venions

|              | stem | desinence |
| ------------ | ---- | --------- |
| 1st pers. s. | -    | -e        |
| 2nd pers s.  | -    | -es       |
| 3rd pers. s. | -    | -e        |
| 1st pers. p. | -    | -ions     |
| 2nd pers p.  | -    | -iez      |
| 3rd pers. p. | -    | -ent      |

## Regular and two-stem verbs

|              | parler           | finir             | vendre          | venir             |
| ------------ | ---------------- | ----------------- | --------------- | ----------------- |
| 1st pers. s. | que je parle     | que je finisse    | que je vende    | que je vienne     |
| 2nd pers s.  | que tu parles    | que tu finisses   | que tu vendes   | que tu viennes    |
| 3rd pers. s. | qu'il parle      | qu'il finisse     | qu'il vende     | qu'il vienne      |
| 1st pers. p. | que nous parlions | que nous finissions | que nous vendions | que nous venions |
| 2nd pers p.  | que vous parliez | que vous finissiez | que vous vendiez | que vous veniez  |
| 3rd pers. p. | qu'ils parlent   | qu'ils finissent  | qu'ils vendent  | qu'ils viennent   |

Same pattern: *prendre → prenne / prenions*, *boire → boive / buvions*, *devoir → doive / devions*, *recevoir → reçoive / recevions*, *voir → voie / voyions*, *croire → croie / croyions*. 注意 -er 动词单数和 3rd pl. 与直陈式现在时同形；*nous/vous* 形式与 imparfait 同形。

Forms shown without *que*.

| 2nd pers s.  | sois    | aies   | ailles   | fasses    | puisses    |
| 3rd pers. s. | soit    | ait    | aille    | fasse     | puisse     |
| 1st pers. p. | soyons  | ayons  | allions  | fassions  | puissions  |
| 2nd pers p.  | soyez   | ayez   | alliez   | fassiez   | puissiez   |
| 3rd pers. p. | soient  | aient  | aillent  | fassent   | puissent   |

|              | savoir    | vouloir    | valoir    |
| ------------ | --------- | ---------- | --------- |
| 1st pers. s. | sache     | veuille    | vaille    |
| 2nd pers s.  | saches    | veuilles   | vailles   |
| 3rd pers. s. | sache     | veuille    | vaille    |
| 1st pers. p. | sachions  | voulions   | valions   |
| 2nd pers p.  | sachiez   | vouliez    | valiez    |
| 3rd pers. p. | sachent   | veuillent  | vaillent  |

Impersonal verbs: *falloir → qu'il faille*; *pleuvoir → qu'il pleuve*.

注意 *être, avoir* 的 *nous/vous* 没有 i：*soyons, ayons*（不是 ❌ *soyions*）。*aller, vouloir, valoir* 是双词干：*aille / allions*。

# Use

## Will, wish, order

> Je veux que tu **viennes**. -> I want you to come.

## Feeling

> Je suis content que vous **soyez** là. Elle a peur qu'il **pleuve**.

## Doubt, possibility

> Je doute qu'il **sache** la vérité. Il est possible qu'elle **fasse** erreur.
> but probability → indicative: Il est probable qu'il **viendra**.

## Necessity

> Il faut que je **parte**. Il est nécessaire que vous **puissiez** répondre.

## After certain conjunctions

See [[Subordinate conjunction 从属连词 conjonction de subordination|subordinate conjunction]].
| conjunction       | meaning      | example                                       |
| ----------------- | ------------ | --------------------------------------------- |
| bien que, quoique | although     | *Bien qu'il **soit** malade, il travaille.*   |
| pour que, afin que | so that     | *Je parle fort pour qu'on m'**entende**.*      |
| avant que (ne)    | before       | *Pars avant qu'il (ne) **pleuve**.*            |
| sans que          | without      | *Il est sorti sans que je le **voie**.*        |
| à condition que   | provided     | *J'irai à condition que tu **viennes**.*       |
| jusqu'à ce que    | until        | *Attends jusqu'à ce qu'il **revienne**.*       |
| à moins que (ne)  | unless       | *À moins qu'il (ne) **fasse** froid.*          |

*ne explétif*：*avant que, à moins que, de peur que* 后可加一个不表否定的 *ne*（书面语），不要与 [[Negation 否定 négation|negation]] 混淆：*avant qu'il ne parte* = before he leaves.

## Relative clauses

After a superlative (or *le seul, le premier, l'unique*) or an indefinite / hypothetical antecedent (see [[Relative pronoun 关系代词 pronom relatif|relative pronoun]]):
> C'est le meilleur film que je **connaisse**.
> Je cherche quelqu'un qui **sache** parler chinois. (若此人确定存在：*Je connais quelqu'un qui **sait**...*)

## Independent clauses

Wish or 3rd-person order, replacing the [[Imperative 命令式 impératif|imperative]]:
> Vive la France ! Qu'il **entre** ! Ainsi **soit**-il.

# Indicative or subjunctive?

| indicative                              | subjunctive                                    |
| --------------------------------------- | ---------------------------------------------- |
| *Je crois qu'il **est** là.*            | *Je ne crois pas qu'il **soit** là.*           |
| *Je pense qu'elle **a** raison.*        | *Penses-tu qu'elle **ait** raison ?*           |
| *J'espère qu'il **viendra**.*           | (*espérer* affirmative never takes subj.)      |
| *Après qu'il **est** parti...* (norm)   | *Avant qu'il (ne) **parte**...*                |

- *croire, penser, trouver* : affirmative → indicative (certainty); negative or inverted interrogative → usually subjunctive (doubt).
- *espérer que* + indicative (often future).
- *après que* + indicative according to the norm (the event is real); *après qu'il **soit** parti* is very common but criticised.

# Subjonctif passé

subjunctive present of *avoir / être* + [[Past participle 过去分词 participe passé|past participle]]; it marks anteriority:
> Je suis content que tu **aies réussi**. Bien qu'elle **soit partie** tôt...

The imparfait (*qu'il parlât*) and plus-que-parfait (*qu'il eût parlé*) are literary.

English equivalent: usually an infinitive (*I want you to come*), *should*, *may*, or a plain present; English has only relic subjunctives (*God save the Queen*).
