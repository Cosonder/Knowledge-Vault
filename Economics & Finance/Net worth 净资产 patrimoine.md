# Definition

**净资产**（net worth, *patrimoine net*）是某一时点上个人或家庭全部[[Asset 资产 actif|资产]]（assets, *actifs*）的市场价值减去全部负债（liabilities, *passif* / *dettes*）：

$$\text{Net worth} = \sum \text{assets} - \sum \text{liabilities}$$

它是一个**存量**（stock, 某一时刻的余额），而收入、支出是**流量**（flow, 单位时间内的变化）。两者的关系类似积分与导数：一段时间内净资产的变化 ≈ 储蓄（收入 − 支出）+ 资产的价格变动。

法语 *patrimoine* 的含义比 net worth 宽。日常用法中它常指"全部家当"，不一定扣除负债（*patrimoine brut* 与 *patrimoine net* 需要区分）；它还有"遗产、文化遗产"之义（*patrimoine historique*）。按资产类别又分：

- *patrimoine financier*：存款、[[Stock 股票 action|股票]]、基金、人寿保险合同（*assurance-vie*）等金融资产；
- *patrimoine immobilier*：自住房（*résidence principale*）与出租房产，见 [[Real estate 不动产 immobilier|不动产]]；
- *patrimoine professionnel*：企业股权等。

# Formula

记资产为 $A_i$（按当前市价估值），负债为 $L_j$（按剩余本金），则

$$NW = \sum_i A_i - \sum_j L_j$$

追踪时更有用的是**可投资净资产**（investable net worth）：剔除自住房和汽车等不产生现金流、也不打算出售的资产。[[Financial independence 财务自由 indépendance financière|财务自由]]的目标数字应与这一口径比较，因为只有它能支持[[Safe withdrawal rate 安全提取率 taux de retrait|提取]]。

# Example

某家庭的资产负债表（*bilan patrimonial*）：

| 资产 | 金额 (€) | 负债 | 金额 (€) |
|---|---|---|---|
| 自住房 | 300 000 | 房贷剩余本金 | 220 000 |
| PEA（股票账户） | 40 000 | 车贷 | 8 000 |
| *assurance-vie* | 30 000 | | |
| Livret A | 10 000 | | |
| 汽车 | 15 000 | | |
| **合计** | **395 000** | **合计** | **228 000** |

净资产 $= 395\,000 - 228\,000 = 167\,000$ €；*patrimoine financier* $= 80\,000$ €。按可投资口径，用于财务自由计算的是 80 000 €，而不是 167 000 €。

追踪方法：每月或每季度在同一天按同一口径估值，记录总额与分项；看趋势而不是单点。汽车按折旧后价值计，房产按保守市价计，避免"纸面致富"。

# In the book 书中

书中几乎处处用 *patrimoine* 指"资产/财富"，多数时候不明确区分毛额与净额：

- P05-S01："Cherchons à calculer le **patrimoine** dont vous aurez besoin pour atteindre l'indépendance financière." 这里的 *patrimoine* 实际是可投资资产，因为它要靠 4% 提取来产生收入（见 P04、P14-S01）。
- P18-S02："Il faudrait donc un patrimoine important pour avoir le droit de commencer…" 作者反驳"必须先有大量资产才能投资"的观念。
- P26-S01、P35-S01："je gère tout mon patrimoine de façon autonome"——*gestion de patrimoine* 即"财富管理"，*CGP* = *conseiller en gestion de patrimoine*。
- P28-S01："Les frais sont un poison pour votre patrimoine."
- P72-S04："Aujourd'hui, Warren Buffett **pèse** plus de 140 milliards de dollars." 动词 *peser*（"重达"）口语中表示某人净资产有多少。

评价：作者把 *patrimoine* 作为一个笼统概念使用。读者在计算"独立数字"时应自行限定为可投资净资产，否则会把自住房错误地计入。

# Common misconceptions

- **把总资产当净资产**：有大额房贷时，房产市值很高但净资产可能很小，甚至为负。
- **把自住房计入可提取资产**：住房提供居住服务，但除非出售或抵押，否则不产生可支配现金流。
- **高收入 = 高净资产**：净资产取决于累计储蓄与回报，而不是收入水平；高收入高消费者净资产可能很低。
- **只看名义值**：长期比较应按[[Inflation 通货膨胀 inflation|通胀]]调整。

# Self-check 自测

> [!question]- 资产 50 万、房贷余额 35 万、消费贷 2 万，净资产是多少？若资产中 40 万为自住房，可投资净资产大约是多少？
> 净资产 $= 50 - 35 - 2 = 13$ 万。可投资资产为 $50 - 40 = 10$ 万；房贷是以自住房为抵押的负债，通常与房产一起剔除，消费贷则应扣除，因此可投资净资产约 $10 - 2 = 8$ 万。

> [!question]- 为什么 P05-S01 中的 *patrimoine* 不能理解为包括自住房的全部净资产？
> 因为该数字的用途是按 4% 每年出售一部分来产生收入（P04-S03、P07-S02）。自住房不出售就无法提取，计入它会高估距离财务自由的进度。

> [!question]- 净资产一年内增加了，是否说明这一年储蓄了？
> 不一定。$\Delta NW =$ 储蓄 $+$ 资产价格变动 $-$ 折旧。股市或房价上涨可以在零储蓄甚至负储蓄时推高净资产，反之亦然。
