# 综述

French nouns have two numbers: singular (*singulier*) and plural (*pluriel*). Number is marked mainly in writing; in speech the final **-s / -x** is usually silent, so number is heard on the determiner (*le / les, un / des*), by [[Liaison 联诵 liaison|liaison]] (*les‿amis*), or in a few irregular nouns (*cheval / chevaux*). Adjectives, determiners and verbs [[Agreement 配合 accord|agree]] with the noun in number. See also [[Gender of nouns 名词的性 genre des noms|Gender of nouns]].

# General rule: + s

> un livre → des livre**s**
> une table → des table**s**

# Nouns ending in -s, -x, -z: invariable

> un bras → des bras, une voix → des voix, un nez → des nez

# Special endings

| singular        | plural     | examples                                           | exceptions (+ s)                                      |
| --------------- | ---------- | -------------------------------------------------- | ----------------------------------------------------- |
| -au, -eau, -eu  | **+ x**    | un tuyau → tuyaux, un bateau → bateaux, un jeu → jeux | un landau → landaus, un pneu → pneus, un bleu → bleus |
| -al             | **-aux**   | un cheval → chevaux, un journal → journaux         | bal, carnaval, chacal, festival, récital, régal → -als |
| -ail            | + s        | un détail → détails                                | bail, corail, émail, soupirail, travail, vitrail, vantail → **-aux** |
| -ou             | + s        | un trou → trous, un clou → clous                   | bijou, caillou, chou, genou, hibou, joujou, pou → **-oux** |

# Irregular plurals

| singular  | plural       | remark                                       |
| --------- | ------------ | -------------------------------------------- |
| un œil    | des **yeux** | (but *des œils-de-bœuf*, architecture)        |
| le ciel   | les **cieux** | *des ciels* in painting / climate            |
| l'aïeul   | les **aïeux** (ancestors) / les aïeuls (grandparents) |           |
| monsieur  | **messieurs** | also *madame → mesdames*, *mademoiselle → mesdemoiselles* |
| un bonhomme | des **bonshommes** |                                       |

Pronunciation changes: *un œuf* [œf] → *des œufs* [ø], *un bœuf* [bœf] → *des bœufs* [bø], *un os* [ɔs] → *des os* [o].

# Compound nouns

The rule depends on the nature of the elements: only nouns and adjectives can take the plural; verbs, adverbs and prepositions are invariable.

| structure                 | plural                         | example                                      |
| ------------------------- | ------------------------------ | -------------------------------------------- |
| noun + noun (apposition)  | both                           | un chou-fleur → des chou**x**-fleur**s**     |
| adjective + noun          | both                           | un grand-père → des grand**s**-père**s**     |
| noun + *de* + noun        | first only                     | un chef-d'œuvre → des chef**s**-d'œuvre      |
| verb + noun               | noun only (1990 reform)        | un tire-bouchon → des tire-bouchon**s**, un ouvre-boîte → des ouvre-boîte**s** |
| adverb / prep. + noun     | noun only                      | un avant-goût → des avant-goût**s**          |
| verb + verb / invariable words | invariable                | un laissez-passer → des laissez-passer       |

# Nouns used mainly in the plural or singular

- Only plural (*pluralia tantum*): *les gens, les mœurs, les fiançailles, les funérailles, les environs, les vacances* (holidays), *les ténèbres, les archives*.
- Change of meaning with number: *la vacance* (vacancy) / *les vacances* (holidays); *la lunette* (telescope) / *les lunettes* (glasses); *le ciseau* (chisel) / *les ciseaux* (scissors).
- Mass nouns are usually singular: *le lait, la patience*.

# Proper nouns and foreign words

- Family names are invariable: *les Dupont*; but dynasties take *-s*: *les Bourbons*.
- Borrowed words take *-s* under the 1990 reform: *des sandwichs, des scénarios, des maximums*.

# Comparison with English

- Nouns uncountable in English but countable in French: *une information / des informations* (information), *un conseil* (a piece of advice), *un meuble* (a piece of furniture).
- Nouns singular in English but plural in French: *les cheveux* (hair), *les bagages* (luggage), *les devoirs* (homework).
- *un pantalon, un short, un jean* are singular in French (*a pair of trousers*).
