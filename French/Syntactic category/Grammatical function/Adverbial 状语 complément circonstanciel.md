# Definition

The adverbial (*le complément circonstanciel*, **CC**) gives the circumstances of the action: when, where, how, why… Unlike the [[Object 宾语 objet|object]], it is not required by the verb: it can usually be **moved** and **deleted** without making the sentence ungrammatical.

> **Hier**, Paul a acheté un livre **dans une petite librairie**.
> → Paul a acheté un livre. (still grammatical)

# Types

| type                              | question                  | example                                                         |
| --------------------------------- | ------------------------- | --------------------------------------------------------------- |
| time 时间 *temps*                  | quand ? combien de temps ? | ***Le matin**, je cours. Il a dormi **toute la nuit**.*         |
| place 地点 *lieu*                  | où ? d'où ? par où ?      | *Nous avons dîné **dans un petit restaurant**.*                 |
| manner 方式 *manière*              | comment ?                 | *Il parle **lentement** / **avec prudence**.*                   |
| cause 原因 *cause*                 | pourquoi ?                | *Il est absent **à cause de la grève** / **parce qu'il est malade**.* |
| purpose 目的 *but*                 | dans quel but ?           | *Il travaille **pour réussir** / **afin que ses enfants soient heureux**.* |
| consequence 结果 *conséquence*     | avec quel résultat ?      | *Il a tant plu **que la rivière a débordé**.*                   |
| means / instrument 手段 *moyen*    | avec quoi ? comment ?     | *Il est venu **en train**. Elle ouvre la porte **avec une clé**.* |
| condition 条件 *condition*         | à quelle condition ?      | ***Avec un peu de chance**, nous gagnerons. **S'il pleut**, je resterai.* |
| concession 让步 *concession*       | malgré quoi ?             | ***Malgré la pluie**, ils sont sortis. **Bien qu'il soit malade**, il travaille.* |
| accompaniment 伴随 *accompagnement* | avec qui ?               | *Elle se promène **avec son chien**.*                           |
| comparison 比较 *comparaison*      | comme quoi ?              | *Il court **comme un lapin**.*                                  |
| opposition 对立 *opposition*       | au lieu de quoi ?         | ***Au lieu de travailler**, il dort.*                           |

# Forms

| form                                         | example                                             |
| -------------------------------------------- | --------------------------------------------------- |
| [[Adverb 副词 adverbe\|adverb]]                | *Il viendra **demain**.*                           |
| noun phrase without preposition (time, measure) | ***Le dimanche**, nous allons au marché.*        |
| [[Preposition 介词 préposition\|prepositional]] phrase | *Il est parti **sans un mot**.*            |
| preposition + [[Infinitive 不定式 infinitif\|infinitive]] | ***Avant de partir**, ferme la fenêtre.* |
| gérondif (*en* + [[Present participle 现在分词 participe présent\|participe présent]]) | *Il s'est blessé **en tombant**.* |
| absolute participle clause                   | ***Le repas terminé**, ils sont sortis.*            |
| [[Subordinate conjunction 从属连词 conjonction de subordination\|subordinate clause]] | *Je partirai **quand il fera beau**.* |

# How to identify

1. **Deletion**: *Il travaille (le soir).* — the CC can go; a COD or COI generally cannot (*\*Il pense.* ≠ *Il pense à son examen*).
2. **Displacement**: *Le soir, il travaille. / Il travaille le soir.*
3. **Accumulation**: several CC can co-occur: *Hier, à Lyon, sous la pluie, …*
4. **Pronoun**: a CC is never replaced by *le / la / les / lui / leur*.

Caution: some place or measure complements are **essential** (*compléments essentiels*) and cannot be deleted — *Il **va à Paris**. Elle **habite à Lyon**. Ce livre **coûte vingt euros**.* Modern grammars treat them as complements of the verb, not as true CC.

# Pronouns *y* and *en* for place

| complement                             | pronoun | example                                     |
| -------------------------------------- | ------- | ------------------------------------------- |
| place where / to (*à, dans, en, chez, sur…*) | **y** | *Je vais **à Paris**. → J'**y** vais. Il travaille **dans ce bureau**. → Il **y** travaille.* |
| place from (*de*)                      | **en**  | *Je reviens **de Lyon**. → J'**en** reviens.* |

The same pronouns replace objects with *à / de* (*J'y pense, J'en parle*), so *y / en* alone does not tell you the function. See [[Personal pronoun 人称代词 pronom personnel|personal pronoun]].

# Comparison with Chinese

- 汉语状语通常位于动词前（我**昨天在图书馆**看书），法语状语多在句末或句首：*J'ai lu **à la bibliothèque hier**.* / ***Hier**, j'ai lu à la bibliothèque.*
- 汉语"补语"不对应法语 *complément*：跑**得很快**（程度补语）在法语里是方式状语 *Il court **vite***；看**完**了（结果补语）则由时态或动词表达 *J'ai **fini** de lire*。
- 汉语"很高兴"里的"很"是状语，而法语 *très* 修饰形容词，属于形容词的修饰语，不是 *complément circonstanciel*。
- 汉语"在北京工作"中"在北京"是状语，法语 *travailler à Pékin* 同样是 CC de lieu；但"住在北京"对应的 *habiter à Pékin* 是必要补语。
