# Definition
**股票**（stock / share，法 action）是股份有限公司发行的、证明股东（shareholder，法 actionnaire）对公司拥有所有权（ownership / equity，法 capitaux propres）并据以取得股息和其他权益的凭证。持有股票即持有公司净[[Asset 资产 actif|资产]]和未来利润的剩余索取权（residual claim）。

英语中 stock 多泛指公司的所有权份额，share 指其中一个单位；英式英语也常用 equities。

# Shareholder rights
- **收益权**：获得股息 / 红利（dividend，法 dividende）。
- **投票权**：在股东大会（general meeting，法 assemblée générale）上表决，选举董事会。
- **剩余财产分配权**：公司清算时，在偿还债务后按比例分配剩余财产（排序在债权人之后）。
- **优先认股权**（pre-emptive right）、知情权等。
- **有限责任**（limited liability）：股东损失以出资额为限。

# Classification
- **普通股**（common stock / ordinary shares）与**优先股**（preferred stock，法 action de préférence）：后者通常有固定股息、优先分配，但一般无投票权。
- 按上市地与币种（中国）：[[A-share A股 action A|A 股]]、[[B-share B股 action B|B 股]]、[[H-share H股 action H|H 股]]、N 股、S 股等。
- 按投资风格：成长股（growth stock）、价值股（value stock）、蓝筹股（blue chip）、周期股（cyclical）、防御股（defensive）。
- 按市值：大盘股（large cap）、中盘股、小盘股（small cap）。

# Return and valuation
股票的持有期收益率由股息和资本利得构成：

$$R = \frac{D_1 + (P_1 - P_0)}{P_0}$$

常用估值方法：
- 市盈率（P/E，price-to-earnings）、市净率（P/B）
- 股利贴现模型（DDM），如 Gordon 增长模型：$P_0 = \dfrac{D_1}{r - g}$
- 自由现金流折现（DCF）

# Example
以 20 元买入某股票，一年内获得每股股息 0.6 元，年末股价 22 元，则收益率为 $\frac{0.6 + (22-20)}{20} = 13\%$。
