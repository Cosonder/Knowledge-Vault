# Definition

A **Coxeter matrix** on a set $S$ is a symmetric matrix $M=(m_{st})_{s,t\in S}$ with entries in $\{1,2,3,\dots\}\cup\{\infty\}$ such that $m_{ss}=1$ and $m_{st}\geq 2$ for $s\neq t$. The associated **Coxeter group** is
$$W=W(M)=\big\langle\, S \;\big|\; (st)^{m_{st}}=1 \text{ for all } s,t\in S \text{ with } m_{st}<\infty \,\big\rangle .$$
A **Coxeter system** (考克斯特系统) is a pair $(W,S)$ where $W$ is a group and $S\subseteq W$ is a generating set such that the canonical map $W(M)\to W$ is an isomorphism, where $m_{st}$ is the order of $st$ in $W$. The cardinality $|S|$ is the **rank**. Since $m_{ss}=1$, every $s\in S$ is an involution, and for $s\neq t$ the relation $(st)^{m}=1$ is equivalent to the braid relation $\underbrace{sts\cdots}_{m}=\underbrace{tst\cdots}_{m}$.

The **Coxeter graph** (Coxeter diagram) has vertex set $S$, an edge $s - t$ whenever $m_{st}\geq 3$, labelled by $m_{st}$ when $m_{st}\geq 4$. $(W,S)$ is **irreducible** if the graph is connected.

**Length.** $\ell(w)$ is the minimal $k$ with $w=s_1\cdots s_k$, $s_i\in S$; such a word is **reduced**.

**Geometric (Tits) representation.** Let $V=\bigoplus_{s\in S}\mathbb{R}\alpha_s$ with symmetric bilinear form $B(\alpha_s,\alpha_t)=-\cos(\pi/m_{st})$ (read $-1$ if $m_{st}=\infty$). Then $\sigma_s(v)=v-2B(\alpha_s,v)\alpha_s$ defines a representation $\sigma:W\to GL(V)$.

# Examples

- $(S_n,\{s_1,\dots,s_{n-1}\})$ with $s_i=(i\;i{+}1)$: type $A_{n-1}$, $m_{s_is_j}=3$ if $|i-j|=1$ and $2$ otherwise. $\ell(w)$ is the number of inversions.
- Dihedral group of order $2m$: type $I_2(m)$, $S=\{s,t\}$, $m_{st}=m$. For $m=\infty$: the infinite dihedral group $\widetilde{A}_1\cong\mathbb{Z}/2*\mathbb{Z}/2$.
- Weyl groups of (finite, crystallographic) [[Quotient root system 商根系 système de racines quotient|root systems]] $\Phi$ with $S$ the simple reflections; here $m_{st}\in\{2,3,4,6\}$.
- Affine Weyl groups $W_{\mathrm{aff}}=Q^\vee\rtimes W$ (e.g. $\widetilde{A}_{n-1}$, a cycle of $n$ vertices for $n\geq 3$).
- Hyperbolic triangle groups $\Delta(p,q,r)$ with $\frac1p+\frac1q+\frac1r<1$.
- Weyl groups of Kac–Moody algebras: $m_{st}\in\{2,3,4,6,\infty\}$ determined by $a_{st}a_{ts}\in\{0,1,2,3,\geq 4\}$.

# Key results

- **Exchange condition** (Matsumoto, Tits). Let $W$ be a group generated by a set $S$ of involutions. Then $(W,S)$ is a Coxeter system iff for every reduced word $w=s_1\cdots s_k$ and $s\in S$ with $\ell(sw)<\ell(w)$ there is $i$ with $sw=s_1\cdots\widehat{s_i}\cdots s_k$. Equivalently the deletion condition holds.
- **Matsumoto's theorem.** Any two reduced words for $w$ are connected by braid relations alone. This is the basis for defining $T_w$ in Hecke algebras and Artin–Tits braid groups.
- **Tits' theorem.** $\sigma$ is faithful. $W$ is finite iff $B$ is positive definite. If $B$ is positive semidefinite with 1-dimensional radical (irreducible case), $W$ is an affine Coxeter group.
- **Classification of finite irreducible Coxeter groups:** $A_n, B_n=C_n, D_n, E_6,E_7,E_8,F_4,H_3,H_4,I_2(m)$. The crystallographic ones (Weyl groups) are those with $m_{st}\in\{2,3,4,6\}$: all except $H_3,H_4$ and $I_2(m)$ for $m\notin\{2,3,4,6\}$. The simply-laced ones ($m_{st}\le 3$) are $A,D,E$.
- **Parabolic subgroups.** For $J\subseteq S$, $W_J=\langle J\rangle$, and $(W_J,J)$ is a Coxeter system. $W_I\cap W_J=W_{I\cap J}$. Each coset $wW_J$ has a unique element of minimal length. These elements form $W^J$, and $w=w^Jw_J$ with $\ell(w)=\ell(w^J)+\ell(w_J)$.
- **Finite case.** There is a unique longest element $w_0$, with $\ell(w_0)=|\Phi^+|$ for Weyl groups. A **Coxeter element** $c=s_1\cdots s_n$ (each generator once) has order the Coxeter number $h$, and $|\Phi|=nh$.
- **Bruhat order** is a graded poset with rank function $\ell$. It governs closure of Schubert cells $\overline{BwB}$ (see [[BN-pair BN对 BN-paire|BN-pair]]).

## Relation to quivers

For a finite connected [[Quiver 箭图 carquois|quiver]] $Q$ without oriented cycles, **Gabriel's theorem** says $kQ$ is representation-finite iff the underlying graph of $Q$ is a simply-laced Dynkin diagram ($A_n,D_n,E_{6,7,8}$), i.e. the Coxeter graph of a finite Weyl group with all $m_{st}\le 3$. Then $M\mapsto\underline{\dim}\,M$ is a bijection from indecomposables to $\Phi^+$. In Bernstein–Gelfand–Ponomarev's proof, reflection functors at sinks and sources lift the simple reflections $s_i$ acting on $\mathbb{Z}^{Q_0}$. The Coxeter functor (essentially $\tau$) lifts a Coxeter element $c$ adapted to the orientation. The non-simply-laced Dynkin types $B,C,F,G$ arise from valued (species) quivers (Dlab–Ringel). The same Cartan–Killing classification governs cluster algebras of finite type (Fomin–Zelevinsky).
